# DJI Mini 5 Pro — 3B Uçuş Simülatörü

Gerçekçi 6-DOF aerodinamik fizik, dinamik hava koşulları, DJI RC 2 Mode 2 kontrol deneyimi ve `Cine / Normal / Sport / ATTI` uçuş modlarıyla geliştirilmiş tarayıcı tabanlı DJI Mini 5 Pro drone uçuş simülasyonu.

## Özellikler
- **6-DOF Drone Fiziği**: 249 g sınıfı aerodinamik sürükleme, 4 motor RPM dağılımı, yer etkisi (ground effect), GPS konum sabitleme, çok yönlü engel algılama, otomatik kalkış/iniş ve Eve Dönüş (RTH).
- **Uçuş Modları (`C · N · S · A`)**: Cine (`6 m/s`), Normal (`12 m/s`), Sport (`18 m/s`) ve GPS'siz tam manuel ATTI modu.
- **Hava Koşulları**: Açık & Güneşli, Gün Batımı, Şiddetli Rüzgar, Yağmurlu, Yoğun Sis, Fırtına (şimşek + gök gürültüsü) ve özel rüzgar hızı/yönü ayarı.
- **DJI RC 2 & Kamera**: Klavye, ekrandaki dokunmatik/fare analog çubukları veya USB Gamepad/RC desteği; 3 eksenli stabilize `4K Gimbal`, `Takip`, `Pilot Gözü` ve `Yörünge` kamera açıları.

## Kurulum ve Çalıştırma

```bash
npm install
npm run dev
```

Tek dosya (çift tıklayıp açılabilen) sürümü üretmek için:

```bash
npm run build:standalone
```
